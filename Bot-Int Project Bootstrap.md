## Turbo vs Concurrently

### Concurrently
**Outil simple** qui lance plusieurs commandes en parallèle dans le même terminal.

```bash
concurrently "npm run dev:api" "npm run dev:web"
```

- ✅ Simple, zéro config
- ✅ Fonctionne sans monorepo
- ✅ Logs colorés côte à côte
- ❌ Pas de cache
- ❌ Pas de gestion des dépendances entre tâches
- ❌ Relance tout même si rien n'a changé

---

### Turbo
**Orchestrateur de monorepo** qui comprend la structure de tes workspaces.

```bash
turbo run dev
```

- ✅ **Cache intelligent** — si le code n'a pas changé, ne rebuild pas
- ✅ **Dépendances entre tâches** — peut builder `api` avant `web` si besoin
- ✅ Conçu pour les monorepos (`apps/api`, `apps/web`, `packages/*`)
- ✅ Pipeline configurable dans [turbo.json](file:///home/josue/Projections/future_stiamond/bot_int/turbo.json:0:0-0:0)
- ❌ Plus complexe à configurer
- ❌ Nécessite `packageManager` dans [package.json](file:///home/josue/Projections/future_stiamond/bot_int/package.json:0:0-0:0) (ce qu'on a corrigé)
